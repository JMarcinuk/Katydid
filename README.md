# Katydid
Katydid is the working title for a simple text editor and organization tool that lets you add taggable entries to collections. It is currently being developed by Joe Marcinuk.

### Mission Statement
I am developing Katydid as a tool for me to organize my writing thoughts in one easy to reach place. I like to write snippets and vignettes as I think of them for later use in my writing projects, and I was looking for an editor that lets me organize a bunch of small text files in a searchable, taggable way without overstuffing my Documents folder. I decided to develop Katydid to do that. I also intend to make it user-friendly for making notes for classes, TTRPGs, and more.
